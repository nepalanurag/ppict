Measured numbers only. Every value below comes from `validation/run_null_simulations.py`, which writes `validation/results/null_replicates.csv` and `null_summary.csv`.

## Related real-data check

[REAL_DATA_REPORT.md](REAL_DATA_REPORT.md), generated by

## What was run

- Monte Carlo replicates per scenario: 400
- Seed rule: replicate r of every config uses seed = seed_base + r (seed base 0)
- Provenance: report rebuilt from the saved per-replicate results file below; replicate count and seed base are read back from that file rather than taken from command line defaults
- Nominal level tested: alpha = 0.05
- Total patients per trial: 150 treated and 150 control
- External cohorts per trial: 500 patients with control outcomes used to train the score, 500 patients with covariates only
- Covariates: 60 features in 12 groups
- Commands: `python validation/run_null_simulations.py --n-rep 400`

The treatment effect is exactly zero in every scenario below, so the rejection rate is the empirical Type I error rate.

### Verdict on the headline claim

No prediction-powered estimator showed a statistically significant increase in the rejection rate above alpha in any scenario, including every corruption of the prognostic score and the covariate-shift scenario. On this evidence the claim held.

Across all 24 prediction-powered scenario and method combinations, the highest observed rejection rate was 0.0675 (poorly_estimated_score / ppi_single), against a nominal 0.05. Its one-sided inflation test gave p = 0.0726.

### Comparison baselines

These are not the claim under test. They are the comparison methods, and one of them fails:

- poorly_estimated_score / lasso_l1: rate 0.0875, inflation test p = 0.0011

The L1 lasso adjustment selects covariates using the same data it then estimates on, with no sample splitting and no correction for the selection. It also produced the narrowest intervals of any method in that scenario. Narrow intervals and a broken rejection rate are the same phenomenon here, and it is the reason this project fits the score on a disjoint cohort and tunes a single scalar rather than selecting covariates inside the analysis.

## Interval widths and implied sample size

Variance ratio is the mean squared standard error over the mean squared standard error of the unadjusted analysis on the same replicates. Because required sample size is proportional to the variance constant, at a fixed allocation the implied sample size reduction equals 1 minus that ratio.

`raw R^2` is the uncentered out-of-sample R squared of the score the estimators received. It is reported because this run did not record rho^2, and it must be read with care: a constant offset in the score drives it sharply negative even though the estimator is exactly invariant to such an offset. The relevant quantity is the squared correlation, which the simulator records for subsequent runs.
