# ppict calculator

A local, single-screen calculator for prediction-powered covariate adjustment in
randomized trials. It runs the Python package in this repository; it does not
reimplement any statistics.

```bash
cd calculator
npm install
npm run dev
# http://127.0.0.1:3040
```

The app expects `../.venv/bin/python`, the virtual environment described in the
repository README. Set `PPICT_PYTHON=/path/to/python` to use another interpreter
that has `ppict` installed.

## How it stays one implementation

The client posts the inputs to `app/api/analyze`. That route writes any uploaded
file to a temporary directory, runs `python -m ppict.cli analyze`, and returns the
JSON from `src/ppict/report.py`. The browser formats numbers and draws the
interval plot. Nothing else.

`../validation/run_calculator_checks.py` sends the same file through the Python
API, the CLI and this route, and compares every estimate, interval and projection.
With the server running it also checks the app path; measured difference on the
example file is exactly zero.

## Data

The default file is `data/simulated_trial.csv`, generated by
`../tools/make_demo_trial.py` with a fixed seed. It is simulated, not patient
data, and is labelled as such in its header and in the interface.

To analyse another dataset, upload a CSV with:

- `y`: the outcome, numeric
- `t`: the arm, 0 or 1
- `f`: the prognostic score, numeric

Optionally add a `cohort` column with the value `external` on rows that carry only
`f`; those rows are the unlabeled cohort for the per-arm estimator. Lines starting
with `#` are treated as provenance notes.

## Exports

The download button saves a complete LaTeX appendix for the current analysis. It
is not compiled in the browser; `latexmk` is a repository check, not an app
dependency. A compiled sample is in `../validation/results/`.
