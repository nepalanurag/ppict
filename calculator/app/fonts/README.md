# Fonts

Self-hosted so the calculator builds and runs without a network request.

| File | Face | Source |
| --- | --- | --- |
| `newsreader-latin.woff2` | Newsreader, variable weight 400 to 600, Latin subset | [Production Type / Google Fonts](https://fonts.google.com/specimen/Newsreader) |
| `ibm-plex-mono-400-latin.woff2` | IBM Plex Mono 400, Latin subset | [IBM Plex](https://fonts.google.com/specimen/IBM+Plex+Mono) |
| `ibm-plex-mono-500-latin.woff2` | IBM Plex Mono 500, Latin subset | [IBM Plex](https://fonts.google.com/specimen/IBM+Plex+Mono) |

Both families are licensed under the SIL Open Font License, Version 1.1. The
licence texts are `OFL-Newsreader.txt` and `OFL-IBM-Plex-Mono.txt` in this
directory.

The files were downloaded from the Google Fonts CSS API as the Latin subsets and
are unmodified. They are used through `@font-face` declarations in
`app/globals.css`.
