What it does

One estimator. Four ways to run it.

  1. 1

    Hold out the score

    The prognostic score trains on patients outside the analysis half.

  2. 2

    Select groups

    Permutation-assisted group lasso, calibrated against a null.

  3. 3

    Tune one value

    PPI++ estimates a single tuning scalar from labeled data.

  4. 4

    Report

    Effect, interval, design projection and SAP appendix.

What this does not show

  • One ACTG split. No split-to-split interval.

  • The external-cohort PPI term is a simulation result.
  • Continuous outcomes and additive effects only.
  • Cost and recruitment time are model projections.
